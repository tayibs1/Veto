The Deterministic Core Loop

A complete end-to-end sandbox. The AI proposes strategies based on the chart, but deterministic math and strict cryptographic ledgers authorize the final run.

1. Multimodal Intake (Interactive)

Select a preset or type your own strategy. Argon reads your text, shown beside the chart, and proposes parameters. Try omitting a parameter to see the risk gate block it.

2. AI Proposal & Spec Lock

If parameters are missing, Veto refuses to guess. If valid, a human signs off and hashes the spec into the ledger.

4. One-Shot Unseen Verdict & Risk Gate

Holdout data unlocks only once per locked spec. The Deflated Sharpe Ratio penalty is applied. Finally, paper trades must pass a deterministic cost and drawdown gate.

Press and hold for one second. A person is approving a single test on data the AI has never seen, and it can't be run twice.

Paper-Order Risk Gate

Paper orders only. Plain code checks each one, and the AI can't override it. Try each control:

A £1,000 paper buy with a 40p fee and 10 bps slippage. Costs are within the 250 bps limit, so it should pass.

The same buy with an £11 fee and 35 bps slippage. Costs go over the limit, so the gate should block it.

The manual emergency stop. While it's on, every new order is halted, whatever it costs.
